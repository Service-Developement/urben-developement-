# الهيكلة التنظيمية والعمليات والتصميم — دائرة التنمية الحضرية

## نطاق المنتج
منصة داخلية لإدارة أعمال دائرة التنمية الحضرية بقسمي أنسنة المدن والسياسات والدراسات الحضرية. الموظف يُنشئ ويسجل ويُعد، ورئيس القسم يُكلف ويراجع ويتحقق، ومدير الدائرة يدير الخطة والأهداف والمؤشرات ويراجع القسمين ويعتمد مخرجاتهما ضمن التفويض. المشروع الخارجي تظل بيانات تنفيذه مملوكة لدائرته المنفذة.

## فصل المستويات
- **التنظيم:** مدير الدائرة، رئيس كل قسم، الموظفون المختصون؛ نطاق البيانات بحسب القسم والتكليف.
- **العمليات:** تسجيل وفحص ثم اختيار عملية متخصصة ومراجعة فنية وقرار إداري وإصدار وتسليم ومتابعة وتعلم.
- **السجلات:** موضوع/معاملة، دراسة، مشروع مرجعي، موقع GIS، بند خطة، مؤشر، قياس، دليل، تنسيق، قرار، تعلم، وثيقة.
- **الواجهة:** الرئيسية للدخول اليومي، لوحة المعلومات للقياس، ملفات العمل للتنفيذ، الوحدات التخصصية للمناهج، التقارير للعرض والتصدير.

## المجموعات الوظيفية
1. الوارد والمقترحات: مصدر داخلي من الموظف أو من دائرة بالبلدية أو جهة خارجية. اسم الجهة إلزامي، وليس اسم الشخص. تفاصيل المشكلة والهدف والوصف والمبررات والنطاق والمستفيدين والمخططات والموارد والآثار والمطلوب تُستكمل حسب المرحلة.
2. السياسات والدراسات الحضرية: إعداد الدراسة وتحليل السياسة وتطوير المعايير وتحليل حالة المدينة.
3. أنسنة المدن: مراجعة مشروعات التطوير، دراسات الأنسنة، مؤشرات الرفاه، الفضاءات العامة، التنقل والمشاة، البيئة الصحية والمتنفسات، الاستدامة البيئية.
4. متابعة المساهمة الحضرية: بيانات مشروع من دائرته المالكة → ربط بالأهداف → خطة متابعة وتقييم → بيانات دورية → تحقق وتحليل → تقييم وتعلم.
5. الفضاءات العامة: سجل موقع GIS موحد، طبقات مرجعية، تقييم حالة الموقع الدوري، الأدلة والتدخلات؛ لا تُعتبر البيانات الأولية حصرًا رسميًا للولاية.
6. الخطة السنوية: مدير الدائرة ينشئ البنود والمستهدفات → القسم يسند → الموظف يقدم تحديثًا موثقًا → رئيس القسم يتحقق → المدير يراجع ويقيّم ويقرر التعديل → تقرير وتعلم.
7. المؤشرات: تعريف معتمد وخط أساس ومستهدف ومصدر ومنهجية → قراءة دورية موثقة → تحقق فني → تحليل وعرض → تفسير الفجوة.
8. المرصد: مصدر ويب معتمد → مادة خارجية منشورة → فكرة مستخلصة قابلة للتحويل إلى مقترح مستقل بعد المراجعة. لا AI.
9. التنسيق والتعلم: خدمات مشتركة مرتبطة بكل ملف لا تسجل نفس المعلومات مرتين.

## مصفوفة الأدلة
- لكل إنجاز: الفترة، النسبة أو الكمية، المخرج، مرجع دليل ومصدر وتاريخ، الملاحظات، قرار المراجع.
- لكل قيمة مؤشر: الفترة، القيمة، مكونات الحساب حيث تنطبق، مرجع دليل ومصدر وتاريخ، حالة التحقق؛ دليل مستقل لخط الأساس والمستهدف.
- لكل تقييم موقع: الفترة، هوية الموقع، معايير الوصول والسلامة والمرافق والظل، الدليل والنتيجة والتوصية.
- لا تُعامل القيمة المفقودة صفرًا، ولا يُعد تحديث الموظف قيمة نهائية قبل تحقق رئيس القسم. كل تعديل يُحتفظ بتاريخه.

## الضوابط الفنية قبل الإنتاج
مصادقة مستخدم فعلية، صلاحيات على مستوى الخادم وقاعدة البيانات والوثائق، سجل تدقيق وإصدارات، مستودع أدلة ومرفقات، تكامل GIS الرسمي، خدمات RSS/APIs مرخصة للمرصد، توليد XLSX/PDF أصلي، النسخ الاحتياطي، أمن المعلومات، إدارة البيانات وصلاحيات الوصول، واختبارات قبول المستخدم. النموذج HTML يعمل محليًا وهو محاكاة للأدوار وليس نظام اعتماد رسميًا.

## قرارات لا تزال بحاجة إلى تثبيت إداري
قنوات المراسلات الرسمية، التفويضات، مدد الإجراءات، الجهة المخولة لاعتماد خطة الدائرة ومؤشراتها فوق مستوى الدائرة عند اللزوم، ملاك البيانات المكانية، دورية القياس، ومستويات نشر التقارير.

## التصميم المستهدف للتنظيم والحوكمة

### الهيكل التنظيمي
مدير دائرة التنمية الحضرية ← رئيس قسم أنسنة المدن / رئيس قسم السياسات والدراسات الحضرية ← الموظفون المختصون بكل قسم.

- **مدير الدائرة:** إنشاء وإدارة خطة الدائرة السنوية وأهدافها ومؤشراتها، الإشراف على أعمال القسمين، مراجعة القرارات والتوصيات المعروضة، تقييم الأداء والإقرار أو الرفع وفق التفويض. لا يقوم بإدخال النتائج التشغيلية نيابة عن الموظف.
- **رئيس القسم:** تنظيم ملفات قسمه والتكليفات، الإشراف الفني، التحقق من الأدلة وقراءات المؤشرات وتحديثات الإنجاز، إرجاع الأعمال الناقصة، رفع التوصيات للمدير. لا يعتمد مشروعًا تتولاه دائرة أخرى.
- **الموظف المختص:** استقبال المقترح أو إنشاؤه ضمن تخصصه، تسجيل اسم الدائرة/الجهة لا اسم الشخص، دراسة وتحليل موضوعاته، تسجيل مشروع للمتابعة، إدخال إنجازات الخطة وقيم المؤشرات مع الأدلة، وتسجيل الدروس أثناء العمل. لا يصدر الاعتماد النهائي لمخرجه.

### الضوابط التفصيلية
صلاحية الإجراء = نوع الدور + نطاق القسم + التكليف + الحالة الحالية + نوع الوثيقة + حدود التفويض. رئيس القسم يستطيع إعادة العمل، لكنه لا يقوم بمهمة الموظف تلقائيًا. لا يسمح تغيير واجهة الدور بالتخطي دون تحقق من هوية المستخدم في النظام الإنتاجي.

## سير العمل المستهدف للمقترح / الملف

1. تسجيل مصدر الطلب (موظف/دائرة داخلية/جهة خارجية/تكليف) مع اسم الدائرة أو الجهة وتاريخ ومرجع الإحالة عند توفره. حساب الموظف يُسجل آليًا للتدقيق دون طلب اسمه.
2. إنشاء سجل رئيسي واحد وفحص وجود سجل سابق وإصدار الوثيقة المدخلة. لا تُرفض فكرة أولية لأن تكلفة المشروع أو المخططات غير متاحة بعد.
3. فحص الاكتمال الأولي والاختصاص. عند النقص: بيان الحقول المطلوبة والمسؤول عن إحضارها دون حذف السجل.
4. رئيس القسم يحدد مسار الدراسة أو يعرض الخلاف بين القسمين على المدير. إذا كان الملف مشتركًا: قسم رئيسي واحد ومساهمات فنية منفصلة.
5. الموظف يحدد سؤال الدراسة والأدلة المطلوبة، ويستعين بسجل GIS أو بيانات السياسات حيث تنطبق.
6. التنسيق خدمة مشتركة عند الحاجة ويمكن إجراء طلبات متعددة بالتوازي؛ لا يُعتبر عدم الرد موافقة.
7. يُعد الموظف التحليل والبدائل والمرئيات والمخرج المحدد لمساره، مع مراجع الأدلة وحدود الاستنتاج.
8. رئيس القسم يتحقق فنيًا ويعيد بملاحظات أو يرفع مخرجًا مكتملًا.
9. مدير الدائرة يراجع على مستوى الأولويات والآثار والقرارات ويعتمد ضمن التفويض أو يرفع للجهة المخولة أو يطلب استكمالًا.
10. يُصدر المخرج ويحفظ برقم ونسخة وتاريخ والجهة المستلمة. يمكن استمرار متابعة الاستجابة في سجل مرتبط، دون تكرار الموضوع الأصلي.
11. تُغلق المعاملة بعد تحقق شروط الإغلاق، مع استمرار أي ملف متابعة مستقل مرتبط.
12. التعلم مرتبط بكل مرحلة وبالملف النهائي؛ توصية التحسين قد تنشئ مهمة أو دراسة أو تحديثًا للخطة.

## تعريفات الحالات والانتقالات
- حالة ملف موضوع: مسودة → مسجلة → مسندة → معالجة فنية → مراجعة رئيس القسم → قرار مدير الدائرة → إصدار → متابعة استجابة أو إغلاق.
- حالات الانتظار مثل طلب رد جهة أو استكمال بيانات تحفظ كسبب انتظار مستقل، حتى لا تضيع الحالة الأساسية.
- خطة: مسودة ← إعداد المدير → معتمدة داخليًا ضمن التفويض → متابعة دورية → تقييم → إصدار معدل مع الحفاظ على تاريخ النسخ.
- إنجاز أو قراءة مؤشر: مسودة أو مقدم → بانتظار تحقق → تم التحقق / معاد للاستكمال. لا يتم حساب الأداء المعتمد من حالة «مقدم».
- مؤشر: مقترح فني → تعريف مدير الدائرة → إصدار معتمد → قراءات دورية. تغيير الصيغة أو وحدة القياس يحتاج إصدارًا جديدًا كي لا تختلط السلاسل الزمنية.

## دليل المتابعة والتقييم
يحدد مدير الدائرة بنود الخطة والمؤشرات. يسجل الموظف لكل فترة الإنجاز، المخرج الفعلي، قيمة التقدم، الأدلة والمصدر والتاريخ، والمعوقات. يتحقق رئيس القسم من صحة المخرج والدليل والحساب. يراجع المدير من لوحة المعلومات التقدم المعتمد والانحرافات والقرارات المطلوبة. لا تجمع نسب بنود مختلفة دون منهجية وزن معلنة، ولا تساوي نسبة الإنجاز التشغيلي أثرًا حضريًا. لكل قيمة مؤشر دورية دليل مستقل ومراجع لخط الأساس والمستهدف. عند نقص الدليل تسجل فجوة ولا تُسجل قيمة صفر افتراضية.

## تصميم تجربة المستخدم

### التنقل الرئيسي
- الرئيسية: أعمال الدور والإجراءات المستحقة وروابط بدء العمل.
- لوحة المعلومات: حالات الملفات، تقدم الخطة الموثق، قياسات المؤشرات المتحقق منها، معوقات وقرارات.
- موضوعات ومقترحات: تسجيل واحد وفرز فني بحسب نوع موضوع العمل.
- خريطة العمليات: منهجيات ومخرجات الـ12 إجراء والمراحل المشتركة.
- قسم السياسات والدراسات: عمليات التحليل والسياسات والمعايير.
- قسم أنسنة المدن: سبعة مسارات تخصصية قابلة للتكليف.
- مشروعات المتابعة: سجل مالك المشروع وبيانات المتابعة لا إدارة التنفيذ.
- الخطة السنوية، المؤشرات، الفضاءات GIS، المرصد الخارجي، التعلم المؤسسي، التقارير.

### سلوك الواجهة
- القائمة والبطاقات تتغير وفق الدور، بينما المجالات المرجعية المشتركة تُعرض لجميع الأدوار عند الحاجة.
- لا تكرار لحفظ المعلومة في شاشات مختلفة؛ تستخدم الشاشات السجل نفسه.
- تظهر كل خطوة مدخلاتها المفقودة ومصدرها والمخرج المطلوب بدل نموذج واحد يفرض جميع الحقول منذ البداية.
- رابط كل دليل من التقرير يعود إلى نسخته ومصدره وتاريخ التحقق.
- عرض اسم الدائرة المالكة للمشروع والدائرة المحيلة بصورة مستقلة، دون اسم شخص مقدم المقترح.
- نظام الألوان هادئ: البنفسجي للعناوين، التركواز للإجراءات الأساسية، مع شعار بلدية ظفار الأصلي دون فصل بصري حاد.

## حزمة اختبارات القبول الأساسية

| السيناريو | معيار القبول |
|---|---|
| إنشاء مقترح من موظف | يحدد النظام قسم الموظف ويحتفظ بالبيانات والمرفقات ولا يشترط اسم شخص |
| مقترح من دائرة أخرى | يمنع التسجيل دون اسم الدائرة، مع مرجع الخطاب عند وجوده |
| إرسال دراسة للمراجعة | يلزم وجود تحليل وتوصية وبيان مصادر الأدلة |
| مراجعة القسم | لا يستطيع الموظف اعتماد مخرجه؛ يستطيع رئيس القسم إعادته أو رفعه |
| اعتماد المدير | لا يستطيع غير المدير تنفيذ الاعتماد في مراحل القرار المخصصة له |
| إنشاء الخطة | مدير الدائرة وحده ينشئ بنود الخطة ومؤشراتها |
| تحديث إنجاز | الموظف يسجل فترة ومخرجًا وقيمة ودليلًا ومصدرًا وتاريخًا |
| تحقق رئيس القسم | التقدم لا يدخل لوحة الأداء المعتمد إلا بعد التحقق |
| قياس مؤشر | لكل قراءة دليل دوري مستقل وتاريخ ومصدر؛ لا تُقبل قيمة بلا دليل |
| مشروع من دائرة أخرى | يظهر اسم الدائرة المالكة، ويظل التنفيذ منفصلًا عن المساهمة الحضرية |
| تقييم فضاء عام | حالة الموقع وتاريخها ودليلها ولا يندمج تقييمان لفترتين مختلفتين |
| المرصد | يظل المصدر والمادة المنشورة والفكرة المستخلصة سجلات مختلفة |
| التصدير | نطاق CSV/PDF يلتزم بصلاحيات الدور؛ الإنتاج يتطلب ملفات XLSX/PDF أصلية |

## الفجوات الباقية قبل اعتبارها منصة إنتاجية
1. اتصال فعلي لبيانات GIS الرسمية وحصر شامل للفضاءات مع مطابقة الهويات المكانية.
2. مصادقة وحوكمة بيانات وتفويضات رسمية على الخادم.
3. مستودع وثائق وأدلة مع نسخ رقمية وتحكم بالوصول ومراجع ثابتة.
4. محرك إجراءات حقيقي مع توقيعات ومراسلات وتصعيد ومهل معتمدة.
5. توليد تقارير PDF وXLSX أصلية قابلة للأرشفة والتوقيع.
6. بيانات حقيقية للمرصد من RSS/API أو فهرسة مسموح بها؛ لا يوجد AI.
7. استكمال تفصيل واعتماد إجراءات الدراسات وأنسنة المدن وبقية العمليات بنفس عمق مسار المقترحات.
8. اختبار قبول رسمي لكل دور وقسم وإجراء، مع اختبار حالات الاستثناء والمراجعة والإعادة.
