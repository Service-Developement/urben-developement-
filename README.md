# منصة عمليات التنمية الحضرية — بلدية ظفار

نموذج تفاعلي باللغة العربية (RTL) لاستعراض عمليات دائرة التنمية الحضرية وصلاحيات الأدوار والخطة السنوية ومؤشراتها والأدلة والمرصد والفضاءات العامة.

## الملفات
- [فتح النموذج على GitHub Pages بعد تفعيله](https://service-developement.github.io/urben-developement-/)
- [واجهة المنصة](index.html)
- [مواصفات العمليات والهيكلة](docs/process-architecture.md)

## نشر الموقع
1. افتح **Settings → Pages** في هذا المستودع.
2. اختر **Deploy from a branch** تحت **Build and deployment**.
3. اختر **main** و **/(root)** ثم **Save**.
4. تحقق من رابط GitHub Pages المعروض في الإعدادات.

> هذا نموذج تفاعلي تجريبي. الصلاحيات فيه محاكاة، ولا يتصل بقاعدة بيانات البلدية أو بنظام GIS الرسمي. يجب عدم رفع بيانات أو مستندات سرية إلى المستودع العام.
